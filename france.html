Baromètre de crise — France

13 indicateurs France / zone euro, adaptés de la littérature sur les récessions et les crises souveraines. Mis à jour le .

Version États-Unis

Score = moyenne pondérée du risque de chaque indicateur (0 = zone sûre, 100 = seuil de crise historique). Les indicateurs sans valeur sont exclus du calcul.

Comment lire

  • 0–33 : zone sûre. 33–66 : vigilance. 66–100 : seuil de crise atteint ou proche.
  • Score global : < 25 calme · 25–50 vigilance, réduire le levier · 50–75 alerte, réduire l'exposition actions · > 75 crise probable sous 6–12 mois.
  • Règle d'or : 3 jauges rouges ou plus parmi les indicateurs de timing = alerte même si le score global reste bas (les crises partent d'un secteur). Les indicateurs d'ampleur (valorisation, dette) pèsent sur le score mais ne comptent pas dans cette règle.
  • Spécificité française : le risque vient autant de l'État (spread OAT–Bund, niveau des taux) que du cycle. Une crise souveraine passe par le spread, une récession classique par la règle de Sahm et le PMI.
  • Pour rafraîchir : « Modifier les valeurs », puis saisir les chiffres depuis le lien de chaque carte (tous gratuits). Les modifications restent tant que la page est ouverte ; pour les figer, éditer le bloc DONNÉES dans le fichier.
